### 16.5 已知限制

### 19.1 转场判据（`navMotionOf` 的唯一口径）

| 场景 | 动效 | 理由 |
| --- | --- | --- |
| 底栏 Tab 之间（明细 ↔ 统计 ↔ 设置） | `FADE` | 三个 Tab 是平级，不该有方向 |
| Tab / 设置页 → 二级页（统计 → 下钻、设置 → 账户管理） | `SLIDE_HORIZONTAL`（从右进、旧页左移） | iOS / Material 的层级感：往里走是从右边推进来 |
| 二级页 → 上一级（下钻回归统计、账户管理回设置） | `SLIDE_HORIZONTAL`（反向） | pop 时按 `initialRoute` 判，保证「哪里来回哪里去」 |
| 任何页 → 记一笔 / 转账表单 | `SLIDE_VERTICAL`（自下而上） | 表单是模态式的新任务，不是层级导航 |
| 表单 → 返回（含从下钻页打开编辑页再返回） | `SLIDE_VERTICAL`（下落） | 一律竖直落回，**不再按下面那一页的类型改横向**，避免「从下钻页编辑一笔，返回时却横向滑」 |

### 19.5 本批的真实失败（如实记录）

1. **转场判据自己写错了**：`poppingAForm_alwaysFallsStraightDown_evenWhenThePageUnderItIsADetail` 第一版断言「下钻页上盖着表单、pop 回下钻页」应该是 `FADE`，跑起来 1 例失败。核对 `navMotionOf` 的设计（pop 时先看 `initialRoute` 是不是 `FORM`）后确认是我断言错，改成 `SLIDE_VERTICAL` —— 表单永远竖直落回，不因为下面那一页是二级页就改横向。
2. **`uiautomator dump` 静默失败导致误点**：第一次 `Tap '统计'` 报告成功，但随后 dump 仍是明细页——当时 `uiautomator dump` 因窗口不 idle 失败、脚本没校验 "dumped to"，`FindNodes` 读的是上一次的旧文档，于是 tap 落到了播放器位置之外的旧坐标；接着 `Tap '娱乐'` 又在明细页命中了流水行，直接打开「编辑」表单。修法：`Dump` 先删本地与设备端 `ui.xml`，循环执行到输出含 "dumped to" 再 pull，pull 不到文件就 throw；并改为**先断言页面特征文本（如「本月洞察」）再点下面的元素**。
3. **操作机器上的全局动画缩放**：取证需要把 `animator_duration_scale` 调到 10，属于改设备全局设置；每轮取证后必须显式还原并用 `settings get` 复核（本轮还原为 1 / 1 / 1.0）。这类「为了看见」的改动和设备上的真实用户设置一样，不能忘。
4. **静态截图片刻的假象**：`anim-09-detail-slide-a.png` 拍到的是放大中的设置页，看起来像「缩放转场」，与源码的横向位移不符。没有据此改代码，而是重拍三帧拿到 `anim-13-detail-b.png` 的双页位移证据，才确认实现与判据一致。

### 19.6 已知限制

- **没有接 Android 14 的预测式返回（predictive back）**：返回手势的预览动画属于系统 `OnBackInvokedCallback` 那一套，本批只做了应用内的 Compose 转场；系统手势预览仍是默认表现。
- **Tab 之间仍是淡入淡出**：三个 Tab 平级，没有方向感是有意的；如果以后希望「明细 ← 统计」有横向手感，要改 `navMotionOf` 的判据，而不是在调用点硬编码。
- **没有读系统「减少动画 / 移除动画」偏好**（规范 AA-7 / 批 F 的 F-4 未做）：当前 `tween` 时长固定 220 / 180 ms，只受系统 `animator_duration_scale` 影响；开了「移除动画」也不会跳过转场。
- **转场只做 tween，没有弹簧 / 手势驱动**：拖拽返回（drag-to-go-back）没有实现，返回仍靠返回键 / 返回箭头。
- **下钻页与明细 Tab 共用同一个 `TransactionsScreen` 但没有共享筛选记忆**：在下钻页点底栏「明细」会落到未筛选的 Tab 实例（这是本轮刻意做的隔离，见 §19.4 第 3 项）；反过来说，用户若想把下钻条件「带走」到 Tab，需要另开交互，本批不做。
- **转场取证依赖放慢动画**：正常速度下 220 / 180 ms 太短，`screencap` 抓不到中间帧；报告里的中间态截图都是在 `animator_duration_scale = 10` 下拍的，正常速度下只能靠体感与代码判据复现。
