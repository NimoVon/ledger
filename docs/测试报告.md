## 10. 未覆盖 / 未验证项（诚实清单）

1. **真机 1 万笔性能未实测**：基准跑在 Robolectric JVM 上，真机数据量达标性只能靠保守推断。
2. **Android 8.0（API 26）真机未测**：只有 minSdk 声明与 Robolectric 覆盖，未在低版本真机/模拟器上跑过。
3. **签名密钥库的保管未验证**：`keystore/` 已被 `.gitignore` 忽略，密钥库与口令只在本机，**没有任何异地备份**；一旦丢失，已安装的包永远无法覆盖升级（只能换 `applicationId` 重装，等于丢数据迁移链）。
4. **崩溃率未量化**：App 无遥测（设计约束），无法给出线上崩溃率；只能以 562 例单测 + 真机手测替代。
5. **Compose 屏幕层覆盖率低**：`ui.settings` 10.3% 等，主要受 SAF/系统对话框限制。
6. **数据库 v1 → v2 迁移无对象**：当前 `@Database(version = 1)` 且无 Migration，上线前自查项暂无对应测试。
7. **覆盖率未设门禁阈值**：`jacocoTestReport` 只出报告，未在构建里卡阈值，可能出现覆盖率回退而不报警。
8. **SQLCipher 未纳入**（用户 2026-10-16 决策）：防 root / 物理镜像的威胁不在当前范围内。
