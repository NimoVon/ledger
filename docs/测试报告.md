### 16.1 「近12个月」与「今年」不是一回事（本批刻意并存）

| 范围 | 起止 | 折线点数 | 环比对象 | 用例事实 |
| --- | --- | --- | --- | --- |
| 近12个月 `LastMonths(2026-10, 12)` | 2025-11-01 – 2026-11-01（半开） | 2025-11 … 2026-10，12 个点**滚动** | 较前12个月（2024-11 … 2025-10） | 上一年的 2025-11-20 那笔 7000 分**算在本段里** |
| 今年 `CalendarYear(2026)` | 2026-01-01 – 2027-01-01（半开） | 固定 2026-01 … 2026-12，12 个点**自然年**，未来月补 0 | 较上一年（2025 全年） | 同一笔 2025-11-20 的 7000 分**不进本段**（`switchingToCalendarYear_excludesLastYearsMonths` 断言合计只剩 3000） |

翻页口径：**箭头一次挪一整段，和 `previous()` 同一段、与相邻段不重叠**（`lastMonths(2026-10, 6).previous() = lastMonths(2026-04, 6)`，`range.from == previous.to`）。这样「较前6个月」用来比的那一段，就是用户按 ‹ 翻过去看到的那一段，两处数字不会互相打脸。

自定义区间：入参闭区间 → 内部存半开（`to = 结束日 + 1 天`）；`daysInclusive ≤ 62` 走 DAY 桶（逐日柱），否则走 MONTH 桶（月度折线）；上限 3660 天。

### 16.4 本批的真实失败（如实记录）

1. **编译失败（成员初始化顺序）**：`e: …/domain/stats/ReportRange.kt:… Variable 'bucket' must be initialized`——`Custom` 里 `daysInclusive` 声明在 `bucket` 之后，而 `bucket` 依赖它。修复：把 `daysInclusive` 提到 `bucket` 之前（Kotlin 属性按声明顺序初始化）。
2. **测试超时揭出翻页口径分歧（1 次）**：`ReportsTrendTest.movingToThePreviousRange_movesTheWholeWindow` 报 `UncompletedCoroutinesError: After waiting for 1m, the test body did not run to completion`——我最初把 `LastMonths.previous()` 写成「窗口滑一个月」（`endMonth - count`），测试等的是「按整段挪」。定稿口径见 §16.1，四类范围的 `previous()` 统一 = `shift(-1)`，并写进 KDoc。
3. **不变量断言写错**：`expected:<2026-01> but was:<2026-12>`——我原本断言 `trend.last().month == YearMonth.from(range.from)`，这只对单月成立；改为 `assertEquals(state.range.months, state.trend.map { it.month })`（对滚动窗口/自然年都成立）。
4. **UI 测试对固定栏做滚动**：`Semantic Node has no parent layout with a Scroll SemanticsAction`——顶部范围标签不在 `LazyColumn` 里，`performScrollTo()` 必然失败。修复：去掉该调用并加注释。
5. **空态断言与实现不一致**：本月一笔流水都没有时走「纯空态」分支，趋势区根本不渲染，原来断言的「本月还没有收支记录」并不是该分支的文案。修复：断言真实的空态说明 + 日柱数为 0，并确认范围弹层仍可从顶部标签打开。
6. **真机走查发现 3 个口径 bug（本批最有价值的失败）**：选「今年」后 ①环比仍写「较上月」②洞察 hint 仍写「日均 / 环比 / 预算」而预算行不显示 ③环形图读屏写死「本月支出分类占比」。三处都是「文案没跟范围走」，已按 §16 第 6 条修复并各补 1 条测试（`change_namesTheComparedRange_insteadOfAlwaysSayingLastMonth`、`donutDescription_namesTheCurrentRange_whenTheLabelIsNotAMonth`、`switchingToACalendarYear_rewordsTheComparisonAndTheDonutDescription`）。

### 16.5 已知限制

- **范围不持久化**：`ReportRange` 只活在 `ReportsViewModel` 里，进程被杀或退出应用后回到「本月」。不做持久化是因为「我上次看的是哪段」不是账本事实，重启后回到当下更符合直觉；要长期偏好再说。
- **从统计页下钻是切底部 tab，不是压栈**：点分类/账户/当日明细会切到「明细」页并带上筛选，此时按系统返回键会退出应用（不是回统计页），要用底部「统计」tab 回来。此行为与批 D 之前的环形图下钻一致，本批未改导航结构。
- **月度折线的一个点 = 整月合计**：>62 天的自定义区间按月聚合，区间若不在月初/月末收尾，首尾两个点是「部分月」的合计（与趋势横轴的月份标签一致，不另行标注）。
- **自然年的未来月补 0**：选「今年」时 12 月还没到也画 0 点，横轴固定 1–12 月便于年度对比，不截断到当前月。
- **预算只在单月范围显示**：跨月/跨年没有「月度预算」含义，预算行与 80%/100% 达成率只在「本月 / 指定月份」出现。
